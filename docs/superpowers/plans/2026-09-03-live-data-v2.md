# Live Data v2 — implementation plan

**Cel:** Rozszerzyć działający LIVE mojV o prawdziwe oceny oraz terminarz/prace szkolne bez pogorszenia logowania, planu i frekwencji.

## Założenia

- Każdy moduł API ma osobny wynik i osobny błąd.
- Awaria ocen lub terminarza nie blokuje planu i frekwencji.
- Helper nie zwraca cookies, tokenów ani kluczy sesji.
- Repo referencyjne służy wyłącznie do ustalenia zachowania, endpointów i kształtu odpowiedzi; nie kopiujemy kodu GPL.
- Nowe parsowanie jest wykonywane w integracji mojV, a helper dostarcza bezpieczne JSON-y z portalu.
- Niezależne requesty w helperze są wykonywane równolegle w kontekście przeglądarki, aby nie wydłużać odświeżenia liniowo.

## Task 1 — parser ocen

Pliki:
- `custom_components/mojv/parsers/grades.py`
- `tests/test_grades_parser.py`

Kontrakt:
- wejście: payload `OkresyKlasyfikacyjne` + mapowanie payloadów `Oceny` wg id okresu,
- wyjście: `tuple[Grade, ...]`, `tuple[FinalGrade, ...]`,
- obsługa `ocenyPrzedmioty`, `przedmiotNazwa`, `kolumnyOcenyCzastkowe`, `idKolumny`, `kategoriaKolumny`, `nazwaKolumny`, `oceny`, `wpis`, `dataOceny`, `proponowanaOcenaOkresowa`, `ocenaOkresowa`,
- niepoprawny pojedynczy wpis jest pomijany, nie wywala całego modułu.

## Task 2 — parser terminarza/prac

Pliki:
- `custom_components/mojv/parsers/schoolwork.py`
- `tests/test_schoolwork_parser.py`

Kontrakt:
- wejście: payload `SprawdzianyZadaniaDomowe`,
- wyjście: `tuple[SchoolWork, ...]`,
- typy: 1 sprawdzian, 2 kartkówka, 3 klasówka, 4 zadanie domowe, pozostałe `other`,
- data preferuje termin odpowiedzi, potem datę wpisu,
- HTML w opisie jest zamieniany na zwykły tekst przed wysłaniem do UI.

## Task 3 — modularne pobieranie API

Pliki:
- `custom_components/mojv/school_api.py`
- `tests/test_school_api.py`

Zmiany:
- plan dostaje `zakresDanych=2`,
- równolegle pobierane: plan, frekwencja, okresy klasyfikacyjne, terminarz,
- okresy klasyfikacyjne są pobierane tylko, gdy znamy `journal_id`,
- po pobraniu okresów oceny dla poszczególnych okresów są pobierane współbieżnie,
- wyniki trafiają do istniejących pól `classification_periods`, `grades_by_period`, `schoolwork` w `RawStudentBundle`.

Pliki:

- `mojv_auth_helper/rootfs/app/server.py`
